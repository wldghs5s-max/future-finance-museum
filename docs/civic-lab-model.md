# 나라살림 랩 — 교육용 계산 규칙

관람객 화면에는 이 문서를 보여 주지 않습니다. 게임 숫자는 가상 살림 점수(0~100)이며 국가채무비율·PYI가 아닙니다.

## 시작 값

- 나라 곳간 48
- 생활 안정 42
- 일자리·활력 52
- 다음 세대 부담 56 (높을수록 짐이 큼)
- 부담의 나눔 44

## 라운드

총 6라운드, 매 라운드 선택지 3개. 한 라운드에서 하나만 고릅니다. 이전 라운드를 바꾸면 그 이후 선택은 지워집니다.

1. 세금: 더 걷기 / 크게 낮추기 / 유지
2. 투자 우선순위: 돌봄 / 일자리·배움 / 크게 늘리지 않기
3. 앞선 투자의 운영·접근성·다른 분야 배분 (2라운드 선택에 따라 갈림)
4. 성과·공백·운영 부담 대응 (이용자 분담 / 뒤로 넘기기 / 방향 전환)
5. 증축·빈쪽 보완·곳간 추스르기
6. 돌봄으로 마무리 / 배움으로 마무리 / 곳간·미래 부담 정리

같은 정책을 의미 없이 반복하지 않습니다.

## 상충

감세와 돌봄·미래 투자·차입성 운영을 겹치면 곳간과 미래 부담이 추가로 흔들립니다. 증세 뒤 한도 강화는 활력을 한 번 더 누릅니다. 만능 조합은 없습니다.

## 마을 시각 (교육용 표현)

관람객 화면에는 이 절을 보여 주지 않습니다. 도형·점으로 변화를 그리지 않습니다.

단계 매핑 (`src/data/civicLab/villageView.ts`):

- 각 정책이 구역별 시설 점수(`visual`)와 운영 점수(`ops`)를 쌓습니다.
- 시설 단계: 누적 2점당 1단계, -3~+3. 초반 2라운드에 최대·최소에 닿지 않습니다.
- 운영 상태: 빠듯 / 보통 / 여유. 건물 단계가 그대로여도 운영·곳간·미래 부담은 달라질 수 있습니다.
- 차입성 선택은 현재 건물을 쇠퇴로 내리지 않고, 미래 부담 숫자와 설명을 바꿉니다.
- 같은 선택 목록은 항상 같은 단계입니다. 공식 예측이 아닙니다.

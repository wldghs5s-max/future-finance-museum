# PDF 시각자료 목록

원본 파일: `재정미래관pdf.pdf` (104쪽, 수정하지 않음).  
조사 도구: 시스템 poppler/ImageMagick 없음. `python3` + 로컬 PyMuPDF(`.tools/py`)로 페이지를 PNG(150–180dpi)로 렌더하고, 임베드 JPEG는 원본 해상도로 추출함.

작업용과 웹 에셋 분리:

| 구분 | 위치 | 용도 |
|---|---|---|
| 작업용 전 페이지 | `work/pdf-pages/` | 조사 (gitignore) |
| 작업용 임베드 | `work/pdf-embedded/` | 원본 JPEG 보관 (gitignore) |
| 작업용 표 크롭 | `work/pdf-selected-crops/` | 재크롭 과정 (gitignore) |
| 웹 에셋 | `public/exhibits/` | 전시에 연결한 파일만 |

차트 JPEG 원문은 HWP ‘차트보내기’라 한글이 붙어 있습니다. 이미지 자체는 재인코딩하지 않았고, UI 캡션만 MD 띄어쓰기를 씁니다.

## PDF ↔ MD 차이 (추정으로 맞추지 않음)

1. **202%**: MD 본문·94쪽에 없음. PDF 90쪽 차트 ‘현행 추세(기준)’ 막대에 있음. 언론 차트 사례로만 소개. PERI 사전 180%와 출처가 다름.
2. **생산연령**: 차트/본문 2022 71.1%→2072 45.8%. 표 2024 70.0%→2072 47.6%(NABO). 병기.
3. **온실가스**: 차트 2018 742.3 / 2023 624.2 / 2024 691.6백만톤. 본문은 2024를 ‘약 2% 감소’, 2018~2024 감축을 ‘약 9,389만 톤’으로 적음(차트 끝점 차 50.7백만톤과 불일치). PDF 내부 불일치.
4. **NDC**: 표는 구간(한국 53~61% 등). 차트 막대는 구간 중간값. 중간값을 확정 목표로 쓰지 않음.
5. **국민연금 소진**: 25쪽 2057→2065, 26쪽 2069, 73쪽 표 2071년(2025 개정·복지부). 병기만.
6. **PYI**: 89쪽 차트 31.8 / 33.4 / 28.5%p. 구 구현의 −8.4 / +12.1 / +42.5%p는 원문에 없음.
7. **1인가구**: 13쪽 차트 2015 27.2%→2052 41.3%. 22쪽 본문 2020 31.2%→2050 39.6%. 출처·시계가 다름.
8. **차트 제목 띄어쓰기**: PDF 임베드 이미지는 붙여 쓰기. MD 제목은 띄어 씀.

원문 불일치는 화면에서 임의로 하나로 고치지 않았습니다.

## 웹 적용 후 대조

- 원본 그림 탭에서 PDF 추출 이미지와, 라벨이 있는 자료만 막대 재구현을 전환할 수 있습니다.
- 표 이미지는 가로 스크롤로 작은 화면에서도 잘리지 않게 했습니다.
- 브라우저 클릭 검증 도구가 이 환경에 없어, 화면 나란히 비교·모바일 실기 확인은 로컬 `npm run dev`에서 직접 봐 주세요.
